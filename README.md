
# Darshan Parekh – GitHub Portfolio

A fast, lightweight portfolio website built with **vanilla HTML/CSS/JS** and deployable via **GitHub Pages**.

## ✨ Features
- Clean, responsive design with dark/light mode toggle
- Index, Projects, and About pages
- Structured data (JSON‑LD) and basic Open Graph tags
- Easy to extend with more projects

## 🚀 Quick Start
1. Create a new GitHub repository (public). You can name it anything, e.g. `portfolio`.
2. Upload the files in this folder to the repo (keep the folder structure).
3. Commit and push to the `main` branch.
4. Enable GitHub Pages: in **Settings → Pages**, set **Source** to `Deploy from a branch`, and choose the `main` branch and root (`/`). Save.
5. Your site will be available at the URL GitHub shows on the Pages screen. It may take a minute to go live.

> Tip: If you want the domain `USERNAME.github.io`, create a repo **named exactly** `USERNAME.github.io` and place these files at the root.

## 🧩 Customization
- Edit text inside `index.html`, `projects.html`, and `about.html`.
- Replace placeholder project links with your real repositories.
- Add a profile photo in `assets/img` and reference it in `index.html` if desired.
- Update contact details in the header/footer.

## 📄 Resume Link (optional)
Add your resume file under `assets/` (e.g., `assets/Darshan_Parekh_Resume.docx`) and link to it from `index.html`.

## 🔐 Notes
- This site is static—no server required. Avoid committing secrets to the repo.
- For custom domains, add a `CNAME` file with your domain and configure DNS with your registrar.

## 🛠 Local Preview
Just open `index.html` in your browser, or serve locally with any static server (e.g., `python -m http.server`).
